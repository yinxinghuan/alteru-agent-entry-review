# AlterU Agent — English product walkthrough, V2

## Purpose

An instructional product film with the pace and polish of an advertisement. The viewer should understand what to type, where to send it, what changes, how to preview it, and how to iterate. The mascot supports the product interface; it is not the subject of the film.

## Source and truthfulness

The chat chrome, bubbles, composer, task cards, progress bars and Preview/Publish actions reuse the existing `alteru-agent-demo/handoff/css/app-ui.css` and Agent screen structure. That handoff is an existing product design reference, not evidence of the current shipping app. Conversation content is scripted for this film. The building sequence and gameplay are illustrative; on-screen labels identify this and the compressed timing. No part of this film measures generation speed or demonstrates a live backend run.

## English script — 90 seconds

| Time | Screen | Viewer learns |
|---|---|---|
| 0–4 | Game encounter teaser | This is the game we are about to make. |
| 4–13 | Product Agent UI: type and send | “Create an RPG in a city where memories are currency.” |
| 13–18 | The city is built | The brief produces a visible setting. |
| 18–26 | Product Agent UI: follow-up | “Make me a forgotten courier. Add one friend who still remembers me.” |
| 26–36 | Courier and companion appear in two successive clips | Characters connect to the premise. |
| 36–45 | Product Agent UI: define a choice | “Two guards block the gate. Let me show the letter or trade a memory.” |
| 45–50 | The encounter is built | A game needs an action and a consequence. |
| 50–56 | Product task card: Preview | The creator enters the result. |
| 56–68 | Simulated play: walk, talk, choose, gate opens | Showing the letter increases trust and opens the gate. |
| 68–76 | Product Agent UI: refine | “Make the guards remember me and let me pass next time.” |
| 76–84 | Simulated second visit | The guard recognises the player and permits entry. |
| 84–90 | Short closing card | Describe. Preview. Play. Refine. |

## Production changes from V1

- Product interface comes from the existing handoff instead of newly invented light-panel UI.
- The creator supplies concrete requirements in successive messages, with visible typing and sending.
- Each request is followed by the corresponding game change.
- Gameplay explicitly shows a quest, movement, two choices, an inventory consequence and a changed return encounter.
- The soundtrack and cuts support the instructional sequence. There is no voice-over in this version.
- The first family branding sequence and unrelated genre montage are removed from this edit.
